# DiagramCloud 1.29.0: V2 standalone continuation

A minor release on top of [1.28.1](../release-1.28/RELEASE_NOTES-1.28.1.md). Document schema stays 1; the model gains optional fields only (`choiceOption.compatibility`, `asset.digest`, `asset.keptDistinctFrom`). V2 is still not complete: the [R4 crosswalk](../product/R4_CROSSWALK.md) and [V2_WORKSTREAM_STATUS](../product/V2_WORKSTREAM_STATUS.md) say which rows each package moved and what stays open.

## What changed

- **Hierarchy rail and Choose parent** ([#89](https://github.com/julian-passebecq/diagramcloud/pull/89), AC05, AC07). `src/core/hierarchy.ts` lists every permitted parent path to a view from explicit drilldown only (never a dependency edge), bounded to 12 and saying when it is truncated; public mode reads publicDocument. A rail after the breadcrumb offers Up, Down, previous/next sibling and previous/next story step, each one action and never a revision. When the deepest open view has more than one parent path, Choose parent picks one; the choice is navigation state only. Canvas cards and sidebar tabs are reached by real Tab presses at 390x844.
- **Evidence forms and compatibility evidence** ([#90](https://github.com/julian-passebecq/diagramcloud/pull/90), R3-AC-30). Schedule blocks and metrics `measure` readings have form editors: errors inline, nothing repaired, one revision and one Undo per edit. A named person can record compatibility evidence on a component-owned choice, with at least one citation; the substitution check reads it, synthetic blocks never count, a removed or reworded requirement is shown ignored, and recording it makes a reviewed decision review-needed. The comparison figure says "measured difference" only for two measured, non-synthetic, cited readings.
- **Host refusals and packaging** ([#91](https://github.com/julian-passebecq/diagramcloud/pull/91), AC15). A return kind the host has no route for is refused as `unsupported-route`; every refusal hands the original input back unchanged, and the webview offers Download return file for it. The installed-VSIX test passed in VS Code 1.142.0 and in a local Cursor 3.24.18. `npm run package:candidate -- --dry-run` runs in CI on Linux and lists every archive back.
- **Studio environment** ([#92](https://github.com/julian-passebecq/diagramcloud/pull/92), AC06, AC20, AC21). One environment selection drives canvas cards, the navigator and saved contexts. A reported TEST pass shows only in TEST, PROD stays UNKNOWN and not approved, a linked promotion gate is not an executed gate, environments are paired by componentId only, and Bronze/Silver/Gold are refused as environments.
- **Public boundary** ([#93](https://github.com/julian-passebecq/diagramcloud/pull/93), AC25, AC16, AC13, AC29, R3-AC-24, R3-AC-25). Noninterference tests show hidden objects move no public route, bound, count, story gap or public layout. Public targets refuse a private ID exactly like a nonexistent one. Lens commit lists are never read. A failed concept-packet regeneration serves an error, never the previous packet, and the preview origin cannot reach host routes, a shell, environment values or cookies.
- **Writes, imports and duplicates** ([#94](https://github.com/julian-passebecq/diagramcloud/pull/94), AC18, AC30, AC17, AC27). A repository save that fails after the write started reports "outcome unknown, not saved"; the next save re-reads first and never retries blindly. Unknown top-level modules are imported only after the author confirms that exact list, and are dropped. Images record a local sha256 digest; identical bytes offer reuse or keep both, and keep both persists.
- **Independent journeys and instruction files** ([#95](https://github.com/julian-passebecq/diagramcloud/pull/95), AC01, AC02 partly, AC10, AC22, AC28, R3-AC-18). The scanner reads AGENTS.md, CLAUDE.md, .cursorrules and Copilot instructions as declared-rule controls with enforcement UNKNOWN. dbt, Spark and SQL keep distinct kinds; scans are bounded and cancelable; "complete for selected purpose" is defined in `src/intelligence/readiness.ts`.
- **Artifact entry and declared-workflow playback** ([#96](https://github.com/julian-passebecq/diagramcloud/pull/96), AC03, AC04, AC08). An Artifacts entry leads from images, datasets, storage components and declared checks to citing components and producer/consumer traces. Unique components and repositories are counted apart from memberships. Play declared steps shows a presented sequence with "No run data: times and outcome UNKNOWN".
- **Integration.** Version 1.29.0; a race in the watched concept-host test (it failed twice in CI on #96) is fixed by letting the file watcher take its first reading before the first save.

## Limits

- Navigator, search and story steps still open their default parent path; the rail has no shortcuts beyond Tab and Enter.
- Compatibility evidence is recorded only on component-owned choices. The environment selection is not carried by deep links, and there is no approval model.
- Public figures still print viewSpec omission counts ("N private or unreachable component(s) removed"); whether a strict no-count rule forbids them is an open product question. No host calls `acceptPublicReturn` and there is no intake target.
- The uncertain-write receipt lives in memory only. A re-encoded image can only be flagged as a possible duplicate by name.
- The readiness panel has no completeness badge, and the UI folder picker does not pass an AbortSignal to the scanner.
- Owner decisions stay open: AC02 profile levels, AC09 run/attempt model, AC11 Brain evidence.
- The VS Code and Cursor host tests run on a local desktop only; extension update, signing and Marketplace are not proven. Only Chromium is qualified.
