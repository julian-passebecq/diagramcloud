Organization/project/family/state/origin/search filters drive the explorer and canvas. Group collapse is a transient projection of explicitly supplied membership, with original stable IDs and endpoints retained for inspection. Parent views remain above children. Import limit is 4 MiB; schema limit 10,000 nodes is not a canvas promise: a paged selection admits at most 450 authoring nodes. Any omitted scope is reported. Filters and grouping never rewrite memberships, positions or facts.

Reimport preserves authored captions, layout, visibility and attachments. A generation recollected later with identical facts is not a conflicting new generation; different facts at the same generation are refused. Private generation receipts remain private even if their block visibility is edited. Missing input is uncertainty. Complete comparable predecessor tombstones permit a separate reviewed removal patch. DiagramCloud never asserts that a producer revision matches a remote repository without evidence.

## CLI and MCP

All CLI commands require `--input <explicit-file.json> --out <new-directory>`. Input is bounded; all results are prepared before output creation, and existing outputs are refused. They never apply, publish or execute a proposal.

| Modes | Inputs/results |
|---|---|
| inspect, query | validated Project; private readiness/assets or public context/report |
| brief, graph | ProjectBrief or GraphSnapshot; private candidate; graph `--current` gives guarded reimport/delta |
| docs, analyze | selected `{path,text}[]`; lexical map or native facts/candidate; optional `--repository-id` and `--revision` retain native contract context |
| profile | validated profile or `{depth,overrides}` |
| bundle, deep | `{files,profile,repositoryId,revision}`; generated private AnalysisBundle/cache key; deep optional `--current`/`--select` yields reviewed syntax projection |
