# R4 crosswalk: work packages and acceptance to code and tests (1.28.1)

**Scope.** This maps the R4 implementation packet (DiagramCloud_Implementation_R4_2026-10-16: `execution/work-packages.json`, `qualification/new-acceptance.json` and the unchanged inherited rows in `qualification/inherited-acceptance.json`) to what `main` holds at 1.28.0 (rows changed by 1.28.0 say so). The packet itself stays outside the repository. 1.28.0 is a **bounded milestone, not a complete V2**: the original product acceptance IDs (F001-F115, DG rows in [outcome.json](../../outcome.json)) remain authoritative and unchanged, and R4 IDs are supplemental planning labels.

**Status rule.** `implemented` means at least one named test asserts the clause's core, and every such test is cited as `` `file` "exact test title" `` (`tests/r4-crosswalk.test.ts` checks that each cited file exists and contains that title). `partial` means code or content exists but a clause is not covered by a test, or only part of it is implemented. `not implemented` means no code. `unmapped` means no code or test in this repository could be tied to the row; it is left visible rather than guessed. Nothing here is owner verification.
