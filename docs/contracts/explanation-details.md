# Authored explanation details

The existing walkthrough request v1 already accepts a selected case, explicit earlier-step prerequisites, questions and before/after state. The native form now exposes those fields. Review retains them and the original source basis; Apply remains one ordinary revision-guarded patch. Moving or removing a prerequisite does not repair its reference: invalid order/missing steps are refused without losing the draft.

The compiler adds an ordinary private table evidence block to each step note. Its two columns are `Explanation field` and `Authored value`. A `format` row identifies `diagramcloud.explanation-details/1`; exactly one `focus-question` and `source-cut`, an optional `case`, up to 20 `prerequisite` rows and up to eight `question` rows preserve supplied text. The maximum is 32 rows. The source cut is a frozen descriptive reference, not a signature, current source assertion or permission grant. Existing prose/state/code blocks remain readable, and the canonical Project schema does not change.

The companion reads the permitted document first. Contract displays the supplied case/prerequisites and evidence explicitly marked input/output; Questions shows the focus question and supplied questions. Neither tab infers contracts from prose, automatically answers questions, executes steps or converts synthetic content into observations. Private authored answers and named review records use the separate [question-answer convention](question-answers.md), preserving this v1 reader. Existing explanations without the structured block remain readable through their original tabs. An unknown version, unsupported column/key, missing/duplicate scalar or multiple attached records is unavailable; the original table remains in Evidence, with no guessed merge or repair.

Coverage: `tests/explanation-details.test.ts`, retained walkthrough/request/companion source tests, and `tests/e2e/explanation-request.spec.ts` at 1440 and 390 pixels. They cover ordinary preview/apply/reopen, full-source drift, keyboard tab movement, public noninterference and a moved prerequisite refused without a document edit. [Request-file import and validated export](explanation-request-files.md) now preserve the original source binding through the same author form. Opt-in private request-draft autosave and explicit recovery now exist through [draft recovery](explanation-draft-recovery.md). Bounded private answer/review records are described in [question answers](question-answers.md). AI execution remains outside these capabilities.
